# 统计学解释：如何读本次 NHANES 哮喘与 RA 结果

本说明对应 `scripts/year_extension_v1` 已执行代码及更新至 2023 年的结果，不新增模型。RA 指自报医生诊断类风湿关节炎；哮喘指曾被医生或其他卫生专业人员告知患有哮喘。

## 问题目标

在 20—79 岁、疾病状态和预设协变量完整有效的人群中，比较 RA 者与明确无关节炎者的曾患哮喘比例，并估计调整协变量后的关联。疫情前与 2021—2023 年分别估计，跨期合并只作已确认的补充。研究是横断面设计。

## 已知量定义

每位参与者有疾病回答、年龄、性别、种族/族裔、教育程度、贫困收入比（PIR）、实测体质指数（BMI）、吸烟状态，以及官方体检权重、分层编号和层内初级抽样单位编号。

- `MCQ010=1`：曾患哮喘；`=2`：未曾患哮喘。未知、拒答、缺失不能编码为无哮喘。
- RA：`MCQ160A=1` 且关节炎类型为 RA；对照：`MCQ160A=2`。其他关节炎、类型不明及缺失均不进入对照。
- 类型变量：1999—2008 年 `MCQ190`，2009—2010 年 `MCQ191`，2011 年起 `MCQ195`；RA 编码在 2011 年前为 1，之后为 2。以逐周期字典为准。
- 年龄分类为 20—39、40—59、60—79 岁；BMI 分类为低于 18.5、18.5 至低于 25、25 至低于 30、不低于 30；PIR 分类为低于 1、不低于 1。主回归中三者保持连续形式。
- 性别、种族/族裔、教育和吸烟用分类变量；参考组及实际水平见 [数据说明](data-and-reproduction.zh.md)。

## 未知量定义

需要从数据估计：各组加权哮喘比例、调整后的 RA 与哮喘优势比及其不确定性、年龄和性别的交互、两个时期的关联差异。未观测混杂、自报疾病错误、疾病发生先后和生物学机制不能由这些估计确定。

## 每个符号解释

以下所有公式均使用本表已定义符号。

| 符号 | 含义 |
|---|---|
| $i$、$n$ | 某一分析集合中的参与者编号、人数 |
| $y_i$ | 第 $i$ 人的曾患哮喘指标，1 为有、0 为无 |
| $r_i$ | 第 $i$ 人的 RA 指标，1 为 RA、0 为明确无关节炎 |
| $x_{ij}$、$j$、$K$ | 第 $i$ 人的第 $j$ 个协变量编码、协变量编号及编码列数；分类变量可占多列 |
| $W_i$、$w_i$ | 官方体检权重、本分析构造的权重 |
| $d_i$、$D$ | 官方权重覆盖时长、分析目标包含的已观测发布块总时长，单位为年 |
| $\widehat p$、$p_i$ | 从数据估计的加权比例、模型给定 RA 和协变量时第 $i$ 人的哮喘概率 |
| $\alpha$、$\beta$、$\gamma_j$ | 截距、RA 的回归系数、第 $j$ 个协变量的回归系数 |
| $\eta_i$ | 第 $i$ 人的线性预测值，即截距与各变量系数乘积的和 |
| $\mathrm{odds}(p)$、$\mathrm{OR}$ | 概率 $p$ 对应的优势（有/无的概率之比）、两组优势之比 |
| $\log$、$\exp$ | 自然对数、自然指数，两者互为逆运算 |
| $\sum$ | 对指定范围内各项求和 |
| $\widehat\beta$、$s$ | RA 系数的估计值、考虑复杂抽样后的标准误 |
| $H$、$J_h$、$h$、$\nu$ | 有贡献的抽样层数、第 $h$ 层的 PSU 数、层编号、推断使用的设计自由度 |
| $t_{0.975,\nu}$、$T_\nu$、$\Pr$ | 自由度为 $\nu$ 的 t 分布第 97.5 百分位数、服从该 t 分布的变量、概率运算 |
| $P$ | 双侧检验得到的 P 值 |
| $e_i$、$\delta$ | 时期指标（最新时期为 1，疫情前为 0）、RA 与时期乘积项的回归系数 |
| $\widehat\pi_i$、$w_i^*$ | 选择模型估计的成为完整病例的概率、选择加权补充分析的权重 |
| $a$、$\widehat p_i(a)$、$\widehat P(a)$ | 统一代入的 RA 状态 0 或 1、在该状态下模型预测概率、其加权平均 |
| $\widehat\Delta$ | 两个标准化比例之差，以百分点表示 |
| $p_{\mathrm{RA}}$、$p_{\mathrm{control}}$ | 最小例子中 RA 组和无关节炎组的加权哮喘比例 |

PSU 是初级抽样单位。帽号表示根据本次数据估计；95% CI 是 95% 置信区间。矩阵形式的方差计算由脚本执行，本说明不引入未定义的矩阵符号。

## 公式从哪里来

1. **加权比例**来自“估计的哮喘总人数 / 估计的总人数”。调查权重反映不同抽中概率等设计因素；本研究含实测 BMI，故用体检权重。见 [CDC 权重说明](https://wwwn.cdc.gov/nchs/nhanes/tutorials/weighting.aspx)。
2. **Logistic 模型**把 0 到 1 的概率转换成可取任意实数的对数优势。RA 系数取指数得到条件优势比。
3. **标准误**使用分层、PSU 和权重进行 Taylor 线性化：将估计量在拟合值附近近似展开，先聚合同一 PSU 的贡献，再根据同层 PSU 间变化估计方差。普通独立样本公式不能代替该过程。见 [CDC 方差说明](https://wwwn.cdc.gov/nchs/nhanes/tutorials/varianceestimation.aspx)。
4. **跨期补充的时长权重**是本方案定义混合目标人群的规则。它不能消除抽样设计及时期差异，也不能使调查空档获得实际观测。2021—2023 年官方提醒通常不建议直接与此前周期合并，参见 [DEMO_L 分析说明](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DEMO_L.htm)。因此分时期结果必须保留。

## 一步一步推导

### 1. 从原始回答到分析集合

按 `SEQN` 一对一连接 DEMO、MCQ、SMQ、BMX；核验编号唯一性和连接人数。保留不同缺失原因，再依次应用年龄、体检设计、疾病状态及协变量资格。`eligible=TRUE` 是最终完整病例；主模型 M0 至 M3 使用相同的人。

抽样设计先在有有效体检设计信息的较大数据框上建立，再用 `subset()` 指定完整病例子总体。不能先只留下完整病例，再忽略原始设计结构。数据附件为此保留完整框和资格标志。

### 2. 权重与比例

$$w_i=W_i\frac{d_i}{D},\qquad \widehat p=\frac{\sum_{i=1}^{n}w_i y_i}{\sum_{i=1}^{n}w_i}.$$

1999—2002 年两份发布数据共用官方四年体检权重，其每条记录的时长因子均为 4，不能先另造两个独立两年权重。2003—2016 年为两年权重；2017—2020 年 3 月 P 文件为 3.2 年特殊权重，替换单独的 2017—2018 年文件以避免重复。

疫情前分母为 21.2 年，跨期补充分母为 23.2 年；2021—2023 年单独分析直接用其官方两年体检权重。后者对应时长分子、分母均为 2，比例为 1。

人数报告未加权人数，患病比例报告加权估计。比例 CI 采用 `svyciprop(method="logit")`，使用相应子总体的设计自由度。分类比较用 `svychisq(statistic="F")` 的 Rao–Scott 设计校正检验。

### 3. 从概率到调整后的 OR

$$\mathrm{odds}(p_i)=\frac{p_i}{1-p_i},\quad
\log\{\mathrm{odds}(p_i)\}=\eta_i=\alpha+\beta r_i+\sum_{j=1}^{K}\gamma_jx_{ij}.$$

先在相同协变量编码下令 RA 为 1，再令 RA 为 0。两者的截距及协变量项相同，作差后只剩下 RA 系数。因此两组对数优势的差为 $\beta$，两组优势的比为：

$$\mathrm{OR}=\exp(\beta).$$

模型顺序为 M0 未调整；M1 加年龄、性别、种族/族裔；M2 再加教育、PIR；M3 再加 BMI、吸烟。模型由方案预定，不按 P 值筛选变量。使用 `svyglm(..., family=quasibinomial())`，由复杂抽样设计计算方差。

### 4. 标准误、区间与检验

本次系数推断显式采用子总体设计自由度：

$$\nu=\sum_{h=1}^{H}J_h-H.$$

主回归对应疫情前 163、最新时期 15、跨期 178。部分比例或亚组的自由度不同，应以其结果行的 `df` 为准。这里未使用“设计自由度减去回归参数数目”的默认残差自由度；该选择已写进代码与结果表。

先在对数 OR 尺度计算区间，再将两个端点取指数：

$$95\%\mathrm{CI}=\left[\exp(\widehat\beta-t_{0.975,\nu}s),\ \exp(\widehat\beta+t_{0.975,\nu}s)\right].$$

对“RA 系数为 0”的双侧检验为：

$$P=2\Pr\{T_\nu\geq |\widehat\beta/s|\}.$$

整体交互用相应设计 Wald F 检验；年龄三组的交互联合检验两个系数，性别两组检验一个系数。

### 5. 时期差异

跨期补充先在 M3 上加入发布周期分类变量（P1），再加入年龄及 PIR 的非线性项（P2）。时期交互模型再加入 $r_i e_i$，其系数为 $\delta$。周期分类变量已吸收时期主效应，避免重复放入共线的时期主效应。

疫情前 RA 对数优势差为 $\beta$，最新时期为 $\beta+\delta$。先相减得到 $\delta$，再取指数。下式带 latest 和 prepandemic 下标的 OR 分别指同一个交互模型内的最新时期和疫情前 OR：

$$\frac{\mathrm{OR}_{\mathrm{latest}}}{\mathrm{OR}_{\mathrm{prepandemic}}}=\exp(\delta).$$

此处两个带时期下标的 OR 指同一个交互模型内的时期特定 OR；不能直接用两个独立模型的 OR 相除代替。交互 P 值不小于 0.05 只表示未得到充分差异证据，不能证明两个时期等效。

### 6. 已完成的补充分析

- B0 对应 M3；B1 以三结点限制性立方样条处理年龄和 PIR；B2 在 B1 上再处理 BMI 非线性；B3 在 B1 上调整疫情前发布周期（最新时期单独一个发布块，不适用）；B4 在 B1 上使用完整病例选择概率加权。
- 样条结点由疫情前完整病例的未加权第 10、50、90 百分位数预定，并在两个时期共用；不根据显著性改变结点。
- B4 的权重为 $w_i^*=w_i/\widehat\pi_i$。选择概率来自疾病状态和年龄资格已满足者中的完整病例模型；联合影响函数方差同时考虑选择模型和结局模型的不确定性。它依赖选择模型与相关假设，不能保证消除未知缺失机制造成的偏倚。
- 标准化比例先将每人的 RA 编码统一代为 $a$，其余协变量保留，然后平均预测概率：

$$\widehat P(a)=\frac{\sum_{i=1}^{n}w_i\widehat p_i(a)}{\sum_{i=1}^{n}w_i},\qquad
\widehat\Delta=100\{\widehat P(1)-\widehat P(0)\}.$$

这里的 100 用于将比例差换成百分点。该结果是本模型下的调整后对比；横断面数据和现有假设不足以把它解释成干预效果。

## 每一步为什么成立

- 明确无关节炎才属于对照，确保比较对象与原方案一致；疾病状态未知并不等于没有疾病。
- 四模型共用完整病例，避免把模型间人数变化混成调整变量的影响；完整病例选择本身仍可能有偏倚。
- 权重决定各记录对估计的贡献，分层和 PSU 决定方差估计；两者不可互相替代。
- 子总体分析保留研究域与抽样结构的关系，故附件提供域外记录和资格标志。
- 对数尺度的差转成原尺度的比，是指数函数性质；它给出 OR，不能自动转换成风险比或新发风险。
- 交互直接检验“关联是否不同”；一个亚组显著、另一个不显著，不构成差异检验。
- 稀疏单元、收敛、秩、分离及共线性检查支持数值可估计；它们不能验证疾病诊断准确性或排除未测混杂。

## 一个最小例子

直接用本次疫情前数据，不生成模拟结果。根据 [asthma_prevalence.csv](../../outputs/year_extension_20261008_v01/prepandemic/asthma_prevalence.csv)：

- $p_{\mathrm{RA}}=0.222318373053546$；
- $p_{\mathrm{control}}=0.127680181426844$。

先分别除以没有哮喘的比例，再将两个优势相除：

$$\frac{p_{\mathrm{RA}}/(1-p_{\mathrm{RA}})}{p_{\mathrm{control}}/(1-p_{\mathrm{control}})}=1.95310578000749.$$

这与 [未调整模型 M0](../../outputs/year_extension_20261008_v01/prepandemic/regression.csv) 一致。M3 的 OR 为 2.27418017323475，是加入预设协变量后的条件优势比，因此不应要求它等于上述两组粗比例算出的值。

## 最后总结

本次数据支持“自报 RA 与曾患哮喘存在正向横断面关联”。分时期、合并补充、亚组和稳健性结果均保留；不能把统计关联升级为病因、发病风险或机制证实。对照排除了其他关节炎，结果也不能直接推广为“RA 与所有非 RA 人群”的比较。
