## 当前结论

疫情前1999—2020年3月完整病例37,127人，完全调整OR为2.27（95%CI 1.91—2.70）；2021年8月—2023年8月完整病例3,563人，OR为1.97（1.33—2.92）。已观测时期合并并控制发布周期的补充OR为2.25（1.92—2.64）。

这里的结局是“曾患哮喘”，对照是“明确无关节炎”，年龄为20—79岁。结果支持自报疾病的横断面关联，不能说明因果、新发风险或机制。时期交互不足以证明两个时期等效，跨期合并保持补充地位。
