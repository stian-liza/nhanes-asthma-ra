# v0.3 实施阶段入口

当前阶段：实施。正式输入：已确认的v0.3研究计划、范围修订A和同步idea。用户已明确要求继续。

输出：获取manifest、连接与频数QC、表型与缺失盘点、锁定分析配置、复杂抽样估计、敏感性、结果报告和环境记录。

验证标准：三十份DEMO/MCQ/SMQ文件可解析且键唯一；官方频数可复现；主分析2001–2018、补充1999–2018；未询问不当阴性；权重、方差、缺失及模型门槛通过才解释结果。

获取决策：已核对字典，复用两份现有2017–2018文件；全部数据30份，按文件规模预计约100–200 MB（估计，最终以manifest字节数为准）。原始文件保存在移动硬盘`NHANES/raw/`，足够存储。无需下载实验室、饮食或组学原始文件。个体中间结果也放外置盘。服务器已授权但本数据规模可先单线程在Mac完成；必要时将经校验工作副本转服务器。

Gate：pass（范围确认与必需模块获取资格）；checked=用户批准、逐周期字典、移动硬盘与已有文件；weak point=尚无实际联合病例数和缺失率；next move=获取并核查原始记录，模型前冻结缺失策略。

## 2026-09-24 执行更新

上述gate为入口时记录。现已完成获取、766项官方频数核对、表型、复杂抽样、协变量多重插补、主/补充/预设敏感性模型及图表。主分析45,558人；调整患病优势比2.09（95%置信区间1.76–2.49）。插补失败版本明确否决并保留技术记录，正式版本通过审核后才估计关联。
