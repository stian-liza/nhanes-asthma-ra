# T07：模型前分析锁定（v0.3）

正式输入：v0.3计划、范围修订A、`results/qc/sample_flow.csv`、`covariate_missingness.csv`与原始频数检查。冻结时尚未估计回归关联。

## 数据gate

30份文件共150.65 MB；766项官方边际频数全部一致，101316名源受访者跨周期编号唯一。范围端点采用网页显示精度的半个末位单位容差；pandas读取SAS IBM浮点零有时为约5.4e-79，在这些调查数值字段中将绝对值<1e-70还原为0。该修正不删除记录，所有疾病类别精确频数一致。

主分析：2001–2018源样本91351人，成人50201人，两病状态可判定45558人，协变量完整41486人（91.06%）。RA且当前哮喘378人，RA非当前2198人，非RA当前3135人，非RA非当前39847人。补充分析：1999–2018两病可判定50018人，完整45270人（90.51%）。疾病不明不插补；缺失率以各分析域为分母，不能拿全源儿童分母计算。

## 缺失策略

联合完整率未达到95%，启动已批准的协变量多重插补，完整病例为敏感性。主缺失是收入贫困比，主域各两病组约8–10%未加权缺失；教育和吸烟各组均<1%。没有核心协变量>30%缺失或整周期未询问。给定人口学、疾病、其他社会经济/吸烟特征和调查设计后条件随机缺失可作为工作假设；不可由数据证明，收入可能存在非随机漏报，必须作为局限。

实施细化：在1999–2018成人、RA及曾患哮喘均明确的50018人中统一插补协变量；用原始疾病信息构造辅助哮喘类别（从未、当前、既往非当前、曾患但当前未测/未知），不插补哮喘或RA。对2001–2018当前状态明确者取主域；该统一插补支持相同周期曾患、当前vs从未、无关节炎对照和删周期敏感性。1999年当前未询問仍保留未知，不进入当前哮喘模型。

预测变量包含年龄自然样条、性别、族裔、RA、哮喘类别、教育、收入、吸烟、周期、官方设计层、PSU和对数访谈权重。采用mice预测均值匹配；收入使用观测供体保证0–5范围；分类教育/吸烟采用因子量化匹配并仅回填实际类别。方法依据：[mice PMM文档](https://amices.org/mice/reference/mice.impute.pmm.html)。周期与层之间的线性依赖必须记录；疾病和核心社会人口学预测项若被自动移除需审核。固定种子20260923，30套插补，初始10次迭代；检查链轨迹、分布、日志以及主估计蒙特卡洛误差，再决定是否增加迭代/套数。

每套在完整周期源样本上建立survey设计，再定义成人疾病分析域；每套分别拟合、用Rubin规则合并，完整数据自由度取调查模型的残余设计自由度而非人数减参数。主模型M0/M1/M2使用同一域及同一套插补。收入缺失假设仅为条件假设，不声称已消除选择偏倚。

## 锁定输出

主模型：M2（RA、3自由度年龄自然样条、性别、RIDRETH1族裔、周期、五类教育、连续收入贫困比、三类吸烟）。年龄顶端协调为80；内部结点按主域调查加权年龄三分位数确定，存入配置后所有相关模型共用，不按结果改结点。

必做敏感性：完整病例同样本M0/M1/M2、RA对无关节炎、相同周期曾患、当前对从未、2003–2018、逐一去周期、未知关节炎类型分别归RA/非RA的极端归类（以完整病例框架与同口径完整病例主结果比较，避免把插补差别归为疾病定义影响）、线性年龄。全部公布，不选择性报告。1999–2018曾患独立列为补充。

标准化患病比例使用survey::svypredmeans及协方差估计，组间差值用协方差传播，并跨插补合并；非干预效应。描述性百分比同时报告未加权人数与调查方差置信区间。缺失排除与人群特征按周期及疾病分组公开汇总。

发作/急诊、BMI和医疗可及性扩展本轮不启用：最小主分析不依赖这些分支；发作/急诊的新颖性gate未通过。不得把未开展的分支报告为阴性。

Gate：pass（进入预设主模型前的工作假设与样本门槛）；checked=官方频数、连接、疾病规则、四格人数、缺失分布；weak point=插补收敛/设计残余自由度仍须运行验证，收入非随机缺失和疾病误分类不可排除；next move=先生成插补与设计诊断，再估计及报告完整敏感性结果。
