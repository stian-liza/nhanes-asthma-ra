# NHANES 哮喘与RA年份更新 v03

## 阅读顺序

先读中文Word/PDF稿件，再查prepandemic、latest与pooled三目录中的CSV。疫情前是扩展主分析，2021—2023为独立时期分析，pooled仅为预设补充。全部估计来自本轮全新原始文件重算；旧冻存稿及原结果不作为新数字来源。

## 范围和结果

- 疫情前1999—2020年3月，完整病例37,127人；完全调整OR 2.27（95%CI 1.91—2.70）。
- 2021年8月—2023年8月，完整病例3,563人；完全调整OR 1.97（1.33—2.92）。
- 合并40,690人并调整发布周期，OR 2.25（1.92—2.64）。
- 线性交互模型中最新/疫情前OR比0.85（0.56—1.28），P=0.430。计算资格通过不代表两个时期等效；跨期合并仅对应已观测发布块按时长加权的混合人群，未覆盖疫情调查空档。
- 疾病口径、20—79岁、无关节炎对照、完整病例、七项协变量、四模型同一样本、年龄与性别亚组均保留。没有新增MR或其他数据库。

## 运行环境和复现

本轮R 4.5.1，survey 4.5；详细包版本见每个分析目录的environment.txt及environment_diagnostics.txt。Python用于官方文档解析和Word生成，需要lxml、python-docx；问卷文本审阅另用pypdf。R需要haven、survey、dplyr、jsonlite、lpSolve、car、ggplot2、ragg及依赖。

代码在仓库 `scripts/year_extension_v1`。压缩包保留仓库相对路径，将其中scripts、docs、outputs放到工作根目录。先安装上述包或配置R_LIBS_USER。代码中的旧R_library目录仅为已安装软件包的搜索路径，不读取旧研究结果。

在仓库根目录执行：

```bash
NHANES_PYTHON=/path/to/python3 bash scripts/year_extension_v1/run_analysis.sh
```

本次所有分析步骤已经实际执行，汇总入口另做语法检查，未为验证入口再次重复下载或重跑模型。获取程序仅允许复用本轮目录中有来源记录且哈希匹配的文件，不复用此前研究数据。异机复现须统一修改脚本中的外置盘根路径，确保目标为真实挂载的移动硬盘；不得将原始数据改存本机。再次复现前应将本交付目录复制备份，脚本会重建同名新版本结果。

正文由build_report.py读取本次CSV与图像生成；validate_report.py核对表格、正文绑定、源文件哈希、统计验证状态与原封存文件。压缩包未包含原封存ZIP，在独立机器可核对其公布哈希；若运行validate_report.py，应提供该只读旧封存文件或单独明确跳过仅该项检查。

PDF使用Codex捆绑LibreOfficeDev 26.8.0.0.alpha0和render_docx.py生成。macOS上需FONTCONFIG_FILE指向scripts/year_extension_v1/fonts.conf，使转换器找到系统Songti SC字体。其他系统应配置可用中文字体；转换后须逐页复查，不能用文字提取替代版面检查。

## 质量检查和已知限制

原始输入独立重读、纳入资格和权重重建通过；三分析集合主模型的独立PSU聚合Taylor方差检查通过。两时期补充分析分别47项和39项独立核验通过；4个周期调整/交互模型独立方差核验通过。模型检查含收敛、秩、线性规划完全/准完全分离、共线性及单元格精度。

一次最新周期补充模型的联合方差差值2.19525427634833e-05超过既定2e-5阈值。处理为将拟合收敛容差收紧至1e-12并重跑关联分析与验证；没有扩大通过阈值。analysis_gate.json保存拟合结束时的阶段状态，其中“needs separation diagnostic”已由其后的model_gate.json通过结果覆盖；最终状态见final_gate.json。
